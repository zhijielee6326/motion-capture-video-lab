# 动捕视频采集与传输实验 — 项目背景

## 一、实验背景

随着虚拟现实（VR）、增强现实（AR）和元宇宙技术的快速发展，动作捕捉技术已成为数字内容生产、远程教育和应急训练等领域的关键使能技术。动作捕捉系统通过光学或惯性传感器实时采集人体运动数据，经处理后可驱动虚拟数字人、进行动作质量评估或生成训练反馈，为"虚实融合"的人机交互提供了技术基础。

本实验课程依托实验室已有的 FZMotion 光学动作捕捉平台，围绕"动捕数据采集 → 数据处理与传输 → 虚拟场景应用"三个核心环节，设计了四个渐进式案例，覆盖验证型与项目型两类实验形态，旨在培养学生对动捕系统全链路的理解与实践能力。

## 四、案例设计背景

### 案例1：动捕驱动虚拟数字人互动教学（验证型）

**背景**：远程教育场景中，教师无法与学生面对面互动。通过动捕技术驱动虚拟数字人替代真人出镜，可实现更具沉浸感的远程课堂教学体验。

**设计目的**：验证动捕系统从数据采集到虚拟数字人实时驱动的完整链路，并通过非理想条件（标记点遮挡、采样率降低）测试系统鲁棒性。

**核心问题**：在光学动捕系统中，标记点遮挡、采样率不足等异常条件如何影响数字人动作质量？系统对异常的容忍边界在哪里？

### 案例2：基于动捕与AI分析的远程体育动作训练评价（项目型）

**背景**：体育训练中，教练需对学生动作进行精确评估，但人工观察难以量化关节角度、节奏一致性等指标。AI 辅助的自动化评分系统可以提供客观、可量化的训练反馈。

**设计目的**：构建一套完整的动作质量 AI 评分系统，支持四维评价（ROM 动作幅度、DTW 节奏一致性、对称性、RMSE 关节误差），并通过故障注入验证评分系统的鲁棒性。

**核心问题**：如何利用关节角度序列进行多维度动作评价？当动捕数据存在缺失或噪声时，评分结果的稳定性如何？

### 案例3：面向虚拟演播的动作捕捉驱动数字人内容生产（项目型）

**背景**：虚拟演播是广电行业和新媒体领域的热门应用方向。动捕驱动的虚拟主播可以实现 24 小时不间断播报，多机位切换可模拟真实导播效果。

**设计目的**：搭建虚拟演播全流程，从动捕数据采集到虚拟场景渲染，结合 AI 辅助脚本生成和人工修订，展示虚拟内容生产的完整链路。

**核心问题**：如何在虚拟演播场景中平衡渲染质量与实时性能？AI 生成的演播脚本在实际动捕约束下需要怎样的人工调整？

### 案例4：面向应急通信演练的动作捕捉驱动沉浸式虚拟仿真（项目型）

**背景**：应急通信抢修演练（如地震、火灾场景）需要大量实地训练资源，且高危场景难以反复演练。通过虚拟仿真，可在安全环境中模拟灾害场景，利用动捕技术记录和评估抢修人员的操作规范性。

**设计目的**：构建应急通信抢修虚拟仿真系统，包含动作识别、AI 多维评价、核心网状态实时联动和故障注入，支持地震/火灾双场景切换。

**核心问题**：如何将动捕动作数据映射到应急抢修流程？如何实现 UE 虚拟场景与 Python 后端的核心网状态实时联动？

## 五、实验创新点

1. **全链路覆盖**：从光学动捕硬件采集，到数据处理中间件，到终端应用（教育/体育/演播/应急），覆盖完整技术栈
2. **实时+离线结合**：案例 1/3/4 采用 LiveLink 实时驱动，案例 2 采用 CSV 离线 AI 评分，展示两种数据流模式
3. **跨系统联动**：案例 4 实现 UE 虚拟场景与 Python Web 后端的 HTTP 联动，演示"人动→数字人动→核心网状态变"的端到端闭环
4. **AI 辅助评价**：案例 2/4 引入规则引擎和角度分析的 AI 评价模块，提供可量化的动作质量反馈
5. **故障注入验证**：案例 2/4 支持标记点遮挡、骨骼绑定偏移、网络延迟等故障注入，验证系统鲁棒性
