# 案例4 UE场景设计方案

## 方案1：山区地震通信抢修

### UE场景布局

```
┌─────────────────────────────────────────────────┐
│                                                 │
│     🏔️ 山体（静态网格体）                        │
│        \                                        │
│         \  🪨 塌方区域（粒子特效+碰撞体）          │
│          \                                      │
│           \   📡 临时基站部署点                   │
│            \       (蓝色光柱标记)                 │
│             \                                   │
│              ───── 🛣️ 道路（被阻断）              │
│                                                 │
│    🧑‍🔧 数字抢修人员（LiveLink驱动）               │
│    📦 通信设备箱（可交互物体）                     │
│    🔌 线缆模型（动态连接线）                       │
│    📱 终端设备（UI面板载体）                       │
│                                                 │
│    [HUD叠加层]                                   │
│    任务进度 | 核心网状态 | AI评分                  │
└─────────────────────────────────────────────────┘
```

### 需要的UE资产

| 资产 | 来源 | 说明 |
|------|------|------|
| 山地地形 | UE地形工具/Landscape | 高度图生成，带草地+碎石材质 |
| 塌方区域 | 静态网格体+Niagara粒子 | 落石+灰尘特效 |
| 通信设备箱 | 自建模/Quixel Megascans | 约0.6m×0.4m×0.3m箱体 |
| 天线模型 | 自建模 | 三脚架+定向天线 |
| 线缆模型 | Spline Cable组件 | 动态弯曲连接线 |
| 终端设备 | 自建模+UMG Widget | 平板电脑模型+屏幕UI |
| 数字抢修人员 | MetaHuman/_mixamo | 接收LiveLink动捕数据 |

### 场景触发事件

```
动作1(拿起设备) → 终端接入状态变为"connecting"
动作3(放置设备) → 用户注册状态变为"registered"
动作4(连接线缆) → 会话建立状态变为"established"
动作7(终端汇报) → 视频回传状态变为"streaming"
```

## UE开发建议

### 最简方案（推荐本周使用）

1. **不建模**，用UE内置的Cube/Cylinder/Cone组合表示设备
2. **地形**用UE默认Landscape或简单平面
3. **特效**用Niagara模板（火焰、烟雾）
4. **数字人**用mixamo免费模型，LiveLink驱动
5. **重点投入UI**（UMG Widget），展示核心网状态和AI评分

### LiveLink对接

```
MotionBuilder (骨骼绑定) → LiveLink Plugin → UE (动画蓝图)
                                         → UMG Widget (UI更新)
```

在UE中创建蓝图，监听LiveLink数据并更新UMG状态面板。

### 核心网状态展示

使用UMG Widget中的进度条+指示灯：
- 绿色圆形 = 已连接
- 红色圆形 = 未连接
- 黄色圆形 = 连接中

通过Web Dashboard的API（`/case4/upload_action`）获取JSON数据，或直接在UE中用HTTP请求获取。
