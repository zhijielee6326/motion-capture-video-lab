# FZMotion CSV 数据字典

## 宽表格式（FZMotion默认导出）

| 字段 | 类型 | 说明 |
|------|------|------|
| frame | int | 帧编号，从0开始递增 |
| time | float | 时间戳，单位秒 |
| {joint}_x | float | 关节X坐标（毫米） |
| {joint}_y | float | 关节Y坐标（毫米） |
| {joint}_z | float | 关节Z坐标（毫米） |

## 39关节点名称

头部: Head, Neck
躯干: Spine, Spine1, Spine2, Spine3, Hips
左臂: LeftShoulder, LeftArm, LeftForeArm, LeftHand, LeftHandThumb, LeftHandIndex, LeftHandMiddle, LeftHandRing, LeftHandPinky
右臂: RightShoulder, RightArm, RightForeArm, RightHand, RightHandThumb, RightHandIndex, RightHandMiddle, RightHandRing, RightHandPinky
左腿: LeftUpLeg, LeftLeg, LeftFoot, LeftToeBase
右腿: RightUpLeg, RightLeg, RightFoot, RightToeBase

## 关键关节角度计算

| 角度 | 点A | 点B(顶点) | 点C |
|------|-----|----------|-----|
| 右肘 | RightArm | RightForeArm | RightHand |
| 左肘 | LeftArm | LeftForeArm | LeftHand |
| 右肩 | Spine1 | RightShoulder | RightArm |
| 左肩 | Spine1 | LeftShoulder | LeftArm |
| 右膝 | RightUpLeg | RightLeg | RightFoot |
| 左膝 | LeftUpLeg | LeftLeg | LeftFoot |
| 右髋 | Spine | RightUpLeg | RightLeg |
| 左髋 | Spine | LeftUpLeg | LeftLeg |

## 文件命名规范

- 标准动作: `STD-{动作类型}-{序号}.csv` / `.fbx`
- 学生动作: `S{学生ID}-{动作类型}-{序号}.csv` / `.fbx`
- 示例: `STD-aerobics-001.csv`, `S001-aerobics-001.csv`

## 采集参数

- 帧率: 100fps
- 标定重投影误差: ≤0.5px
- 坐标单位: 毫米
- 坐标系: 右手系，Y轴向上
